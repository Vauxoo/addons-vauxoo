App

Stock Manual Transfer

Trigger transfers using a specific route, as it were triggered by a reordering rule.

*Useful for: Inventory Managers and Operations Teams.

Manually trigger authorized routes as if they were reordering rules.

Main Features Main Features

Manual transfers restricted to users in the **Can make manual transfers** group.

Routes must explicitly allow **manual transfers** before they can be used.

A new **Operations › Manual Transfers** menu to create transfers on demand.

Installation

  1. Go to Apps and update the app list.
  2. Search for Stock Manual Transfer.
  3. Click Install.
  4. Assign the proper user group and enable routes as shown below.

Usage

Step 1 — Grant the user permission

Add the user to the Can make manual transfers group.

Step 2 — Enable manual transfer in the route

Mark the route as allowed for manual transfers.

Step 3 — Open the Manual Transfers menu

Go to Inventory › Operations › Manual Transfers.

Step 4 — Create a Manual Transfer

Fill the form and validate to auto-create the picking.

Step 5 — System creates moves/picking

Review the generated stock move(s) and picking.
